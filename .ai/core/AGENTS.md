# AI Agents

This directory defines the operational AI workforce for ProjectEcho.

Every AI agent must:

1. Read REVIEW_PROTOCOL.md
2. Read company.md
3. Read workflows.md
4. Read its own role definition
5. Read CURRENT_STATE.md
6. Perform only responsibilities within its role.

The repository is the single source of truth.
No AI may invent architecture or modify approved decisions.
