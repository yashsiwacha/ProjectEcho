# Purpose

The Dashboard is the user's home within ProjectEcho.

Its purpose is to answer one question immediately:

> **"What is the most important thing I should do next?"**

Every section on this page should contribute to that answer.

# Navigation

Persistent sidebar.

Sections:

- Dashboard
- Career Passport
- Evidence
- Competencies
- Recommendations
- Learning
- Goals
- Settings

---

# Top Navigation

Contains:

- Logo
- Search
- Notifications
- User Menu

---

# Hero Section

Display:

Greeting

Current Career Goal

Career Readiness Summary

Primary CTA

Example CTA:

Continue improving Backend Engineering competency.

---

# KPI Cards

Display three primary metrics.

Career Readiness

Competencies Verified

Active Goals

Each card links to its respective page.

---

# AI Insight

Single prominent card.

Contains:

- Observation
- Why it matters
- Supporting Evidence
- Suggested Action

Only one primary insight should be shown to avoid overwhelming the user.

---

# Recommendations

Display 3–5 highest priority recommendations.

Each card includes:

- Priority
- Estimated effort
- Expected impact
- Quick action button

---

# Recent Evidence

Display:

- Latest uploads
- Verification status
- Date
- Linked competency

Primary CTA:

Upload Evidence

---

# Competency Progress

Visual representation of:

- Top competencies
- Growth trends
- Confidence levels

Each item links to detailed competency information.

---

# Learning Progress

Display:

- Active learning paths
- Completion percentage
- Estimated time remaining

Primary CTA:

Continue Learning

---

# Footer

Contains:

- Version
- Privacy
- Help
- Feedback

---

# Responsive Behaviour

Desktop:

Sidebar expanded.

Tablet:

Collapsible sidebar.

Mobile:

Bottom navigation with floating action button for adding evidence.

---

# Primary User Journey

Open Dashboard

↓

Review AI Insight

↓

Review Recommendations

↓

Take Recommended Action

↓

Upload Evidence

↓

Competency Updated

↓

Career Readiness Improved

---

# Design Priorities

1. Clarity
2. Actionability
3. Explainability
4. Minimal cognitive load
5. Evidence visibility

---

# Success Criteria

The Dashboard succeeds when users understand their current status and identify the next meaningful action within 30 seconds of opening the application.
