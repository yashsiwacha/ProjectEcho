---

# Purpose

The Career Passport is the primary identity page within ProjectEcho.

It provides a living, evidence-backed representation of a user's professional capabilities, growth, and career readiness.

The page should answer:

> "Who am I professionally, and what evidence supports that?"

# Profile Header

Display:

- Avatar
- Full Name
- Professional Title
- Current Career Goal
- Location (optional)
- Profile Completion
- Last Updated

Actions:

- Edit Profile
- Share Passport
- Export PDF

---

# KPI Cards

Display:

- Career Readiness Score
- Verified Competencies
- Evidence Count

---

# AI Career Summary

Provide a concise summary including:

- Professional strengths
- Growth areas
- Career direction
- Overall readiness

Every statement should link to supporting evidence.

---

# Competency Matrix

Display:

- Competency categories
- Scores
- Confidence
- Growth trend

Selecting a competency opens detailed evidence.

---

# Evidence Timeline

Chronological timeline showing:

- Projects
- Certifications
- Work Experience
- Assessments
- Achievements

Each entry includes:

- Date
- Evidence Type
- Verification Status

---

# Active Goals

Display:

- Current goals
- Progress
- Target dates
- Milestones

Primary CTA:

View Goal Details

---

# Recommendations

Display:

- Top 3 recommendations
- Expected impact
- Estimated effort
- Related competency

Primary CTA:

Start Recommendation

---

# Export & Sharing

Support:

- Public Share Link
- PDF Export
- Recruiter View (Future)
- QR Code (Future)

---

# Responsive Behaviour

Desktop:
- Full sidebar
- Two-column content

Tablet:
- Collapsible sidebar
- Single-column content where necessary

Mobile:
- Bottom navigation
- Accordion sections

# Primary User Journey

↓

↓

↓

Review Recommendations

↓

---

# Design Priorities

1. Trust
2. Explainability
3. Evidence visibility
4. Professional presentation
5. Shareability

---

# Success Criteria

The Career Passport succeeds when a recruiter or user can understand the user's professional profile, strengths, supporting evidence, and development opportunities within 2–3 minutes.
