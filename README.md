# ProjectEcho — Career Intelligence Platform

Status: Architecture (Governance-first)

ProjectEcho is a Career Intelligence Platform that replaces static resumes with evidence-driven, explainable career profiles. The repository prioritizes governance, architecture, and documentation before implementation.
